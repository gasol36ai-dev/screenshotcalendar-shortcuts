# ScreenCalendar 捷徑配方

ScreenCalendar 的「一鍵長按截圖→寫入行事曆」捷徑配方。

## 匯入步驟（首次）
1. 先開啟：**設定 → 捷徑 → 進階 → 允許不明捷徑**（iOS 靠簽署檔案管控，此開關只開一次）
2. 手機開啟匯入連結：
   `shortcuts://import-workflow?url=<本頁 raw 檔連結>`
   （ScreenCalendar app 內「捷徑自動化」區塊的一鍵匯入按鈕會自動帶這個連結）
3. 匯入頁按「加入捷徑」即完成。

## 配方內容
1. 拍攝螢幕快照（當前畫面）
2. 儲存到照片（捷徑的螢幕快照不會自動進相簿）
3. 等待 2 秒（避免相簿寫入與 app 撈圖 race）
4. 打開 `scal://auto`（ScreenCalendar 自動解析入口）

## 綁手勢
設定 → 輔助使用 → 觸控 → 輔助觸控 → 自訂動作 → 長按 → 選「截圖入行事曆」
